## 🚜 Overview

Farmers do not always receive the best possible value for their produce
because agricultural markets can be fragmented, price information can be
difficult to interpret, and access to large institutional buyers can be
limited.

**FarmGate** is designed as a digital bridge between:

-   👨‍🌾 Individual farmers
-   🤝 Farmer Producer Organizations (FPOs)
-   🏢 Corporate / institutional buyers

The platform combines **market-price intelligence, direct listings,
competitive bidding, AI-assisted decision support, FPO aggregation and a
structured trade-settlement workflow** in one interface.

## 🎯 Problem Statement

The agricultural supply chain can suffer from:

-   Fragmented farmer supply
-   Limited direct access to institutional buyers
-   Lack of transparent and competitive price discovery
-   Difficulty understanding mandi-price movements
-   Coordination challenges when moving from a buyer offer to an actual
    trade
-   Limited digital tools for FPO-level aggregation and selling

FarmGate focuses on the **market-access and transaction-coordination
layer** between producers and buyers.

## 💡 Solution

FarmGate provides a unified workflow where:

1.  Farmers can create produce listings.
2.  FPOs can represent and aggregate farmer supply.
3.  Buyers can publish requirements through RFQs.
4.  Farmers / FPOs can expose produce to multiple buyers.
5.  Buyers can place competitive bids.
6.  The platform can initiate a structured trade / escrow workflow after
    a bid is accepted.
7.  Mandi-price data can provide market context.
8.  Gemini-powered AI can assist with agritech questions and crop-image
    analysis.
9.  Firebase provides authentication and real-time synchronization for
    supported marketplace data.

## ✨ Key Features

### 🌾 1. Mandi Price Hub

-   Retrieves mandi-market information using the Government of India's
    data.gov.in API.
-   Displays commodity, mandi, district, state and price information.
-   Provides market context for selling decisions.
-   Includes a fallback dataset when live data is unavailable.

### 🤖 2. AI Sell / Hold Advisor

The platform provides an AI-assisted decision-support workflow for
questions such as:

-   Should I sell now?
-   Should I hold my produce?
-   What is happening in the mandi?
-   What should I consider before accepting a buyer's bid?

The Gemini integration supports multilingual responses in:

-   English
-   Hindi
-   Marathi
-   Punjabi
-   Telugu

> **Important:** AI responses can fall back to deterministic demo logic
> when the Gemini API is unavailable. The project should therefore be
> presented as an AI-assisted prototype rather than claiming that every
> output is generated by a trained ML model.

### 📷 3. AI Crop Image Analysis

A crop image can be submitted for an AI-assisted quality-analysis
workflow that returns:

-   Grade
-   Estimated moisture
-   Foreign matter percentage
-   Suggested price
-   Sell/Hold recommendation
-   Remarks

When Gemini Vision is unavailable, the current prototype uses a
deterministic fallback engine.

### 🛒 4. Direct Marketplace

Supports:

-   Farmer produce listings
-   Buyer RFQs
-   Produce discovery
-   Buyer/farmer workflows
-   Listing details
-   Bid initiation
-   Trade initiation

### 🔨 5. Live Bidding

FarmGate supports competitive bidding for farmer listings.

Example:

``` text
Farmer / FPO Listing
50 Quintals of Wheat
Starting Price: ₹2,800/qtl

Buyer A → ₹2,900/qtl
Buyer B → ₹3,000/qtl
Buyer C → ₹3,100/qtl
```

The listing tracks bid count and highest bid.

Firebase Firestore is used to synchronize supported bids and listings in
real time.

### 🤝 6. FPO Dashboard

FPOs act as an aggregation layer between multiple farmers and
institutional buyers.

Instead of every farmer negotiating separately:

``` text
Farmer 1 ─┐
Farmer 2 ─┤
Farmer 3 ─┼──► FPO ───► FarmGate ───► Corporate Buyer
Farmer 4 ─┤
Farmer 5 ─┘
```

This enables larger aggregated quantities and improves the ability to
participate in institutional procurement and competitive bidding.

### 💰 7. Trade / Escrow Workflow

After a bid is accepted, FarmGate can create a structured transaction
containing:

-   Agreed price
-   Quantity
-   Gross trade value
-   Platform fee
-   Net farmer payout
-   Buyer information
-   Logistics information
-   Quality information
-   Transaction status

The prototype represents the workflow through stages such as:

``` text
CONTRACT CREATED
       ↓
ESCROW FUNDED
       ↓
LOGISTICS DISPATCHED
       ↓
QUALITY ASSAYED
       ↓
PAYOUT RELEASED
```

> **Prototype note:** The current implementation models the
> escrow/settlement workflow in the application UI. It should not be
> described as a regulated real-money escrow/payment service unless a
> real payment/escrow provider is integrated.

### 🔐 8. Authentication

Firebase Authentication is integrated for supported user authentication
flows.

The application supports role-oriented experiences such as:

-   Farmer
-   Buyer

### 🌐 9. Multilingual Experience

The AI assistant supports multiple Indian languages, helping make the
platform more accessible to farmers.

### 🔔 10. Real-Time Notifications

The application includes browser notifications and
BroadcastChannel-based local synchronization for supported marketplace
events such as new listings and bids.

## ⚙️ Local Development

### Prerequisites

-   Node.js 18+ recommended
-   npm
-   Firebase project
-   Google Gemini API key (for live Gemini functionality)
-   data.gov.in API key (for live mandi data)

### 1. Clone the repository

``` bash
git clone https://github.com/Dagre-aish/farmgate-marketplace.git
cd farmgate-marketplace
```

### 2. Install dependencies

``` bash
npm install
```

### 3. Configure environment variables

Create a `.env.local` file:

``` env
VITE_GEMINI_API_KEY=your_gemini_api_key
VITE_DATA_GOV_API_KEY=your_data_gov_api_key
```

Do **not** commit `.env.local` or any API secret to GitHub.

### 4. Start development server

``` bash
npm run dev
```

The Vite development server will provide a local URL, normally:

``` text
http://localhost:5173
```

### 5. Build for production

``` bash
npm run build
```

### 6. Preview production build

``` bash
npm run preview
```

## ☁️ Vercel Deployment

FarmGate is configured for Vercel deployment.

The project uses:

``` text
Build Command: npm run build
Output Directory: dist
```

The repository also includes a Vercel rewrite so client-side routes can
resolve through `index.html`.

### Required Vercel environment variables

Add the required variables under:

**Vercel → Project → Settings → Environment Variables**

``` text
VITE_GEMINI_API_KEY
VITE_DATA_GOV_API_KEY
```

Make sure the variables are enabled for the **Production** environment
if the production deployment needs them.

After changing environment variables, trigger a new deployment.

## 🔒 Security Notes

Never commit private credentials, service-account keys or secret API
credentials.

For production hardening, the following should be moved behind a
server-side/API layer:

-   Gemini API calls
-   Sensitive third-party API credentials
-   Payment / escrow operations
-   Privileged Firebase operations

Firebase security rules should also be configured according to the
application's production authorization model.

## 🏆 Why FarmGate?

FarmGate is not intended to be only another farmer e-commerce website.

The platform combines multiple stages of the agricultural market-access
journey:

``` text
PRICE INTELLIGENCE
       +
FPO AGGREGATION
       +
DIRECT MARKET ACCESS
       +
COMPETITIVE BIDDING
       +
AI DECISION SUPPORT
       +
TRADE WORKFLOW
       ↓
BETTER DIGITAL MARKET ACCESS
```

The central objective is to make agricultural selling **more informed,
transparent and organized**, while making procurement easier for
institutional buyers.
